# Cinematic Theme for OLED Sets

A dark, high-contrast theme optimized for OLED televisions and cinema setups.

## Features

- **32-Bit True Colour**: Decodes wallpapers in true 32-bit ARGB_8888 (`wallpaper_true_color: true`) to avoid banding on dark gradients and shadows.
- **Frosted Glass Dock**: 6-column translucent dock band (`dock_glass: true`, `dock_opacity: 65`) that lets backdrops show cleanly through.
- **Ambient Glow Off**: Disables icon-tinted ambient halo wash (`ambient_glow: false`) to preserve true OLED pitch black and pure backdrop colors.
- **Idle Clock**: Transitions to a calm drifting clock after 2 minutes of inactivity (`home_idle_clock_minutes: 2`).
